# 交接

## 現在能玩的

開 `/narrative`。這是獨立預覽，不是主畫面。

五分鐘樣板：

1. 大門，陳予。兩個選項都會記住你怎麼進來，獎勵 id 相同，只結算一次。
2. 宮燈教室，林可。留下或先去圖書館，後續句子不同。
3. 圖書館，林可與周安。並列或分開再對照。
4. 把時間調到傍晚再回宮燈。早上這段不會出現，人可以繼續走。
5. 結束後可以改去其他區。雨天才會遇到田徑場那件。

測試面板只在這個預覽頁。正式玩家畫面沒有它。「用這個 seed 重開」先只改畫面上的進度，不覆寫已保存的 fixture。下一個會寫入的動作才覆蓋它。在那之前按「恢復」會回到上次保存。

## 程式入口

- 資料：`content/narrative/`
- 載入、條件、選擇、白名單、驗證：`src/features/narrative/`
- 獎勵只呼叫 `grantQuestReward` 與 `replayFastTravel`
- 主場景的休眠接點：`src/game/rpg/narrative-glue.ts`。`AdventureApp` 沒有 import 它。`MAIN_INTEGRATION` 是 false。

## 不要做的事

- 不要在內容檔寫可執行程式。效果不在白名單就整段取消。
- 不要直接改 HP、背包 store 或 `tamkang-rpg-v2`。
- 不要為了數量複製事件。
- 不要把研究用的校園照片放進 `public/`。
- 不要合併 main，不要發正式站。
