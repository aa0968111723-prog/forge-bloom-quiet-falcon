# 玉綠校園奇幻：第一輪美術實作
日期：2026-11-11（台灣時間）。

本輪依使用者選定的概念方向，實作可動、可即時渲染的程序化 3D 美術。
概念圖是風格參考，並不是遊戲已達成的畫質截圖。

## 已進入主遊戲
- 學生：玉綠外套、米白內搭、短褲、袖口、手部、球鞋鞋帶、分束瀏海與小束髮。
- 面部：立體眼白、虹膜、高光、眉毛、耳朵、鼻與笑線；NPC 保留不同外套色。
- 背包：圓角帆布包、袋蓋、口袋、背帶、扣件及立體小龜吊飾。
- 四種敵人：折頁考卷、報告活頁夾、期中監視者、期末截止日時鐘造型。
- 技能：九學院映射至幾何陣列、書頁、葉光、共振軌道與金幣軌道五種形狀家族。
- 校園：宮燈教室瓦壟及簷下構件、宮燈金屬骨架、杜鵑花帶、圖書館窗框。
- 標題畫面：紙色與玉綠材質，桌面右側保留場景視野。
- Node 路由補入 RPG 樣式，與靜態入口一致。

技能形狀、怪物外觀與動畫僅讀取既有遊戲狀態，未新增第二套傷害、獎勵、
冷卻或模擬時鐘。校園永久 ID、建築輪廓、碰撞、任務與 v2 存檔維持原有規則。

## 資源管理
程序化細節以帶頂點顏色的合併網格呈現，不為每一片花瓣或髮束建立 draw call。
本輪未引入新套件、下載模型或外部材質。

CPU 模型工廠檢查（不是 GPU FPS 量測）：

| 模型 | 高細節網格數 | 三角形數 | 省電三角形數 |
| --- | --- | --- | --- |
| 學生本體與附屬件 | 7 | 12,254 | 沿用同一骨架與造型 |
| 考卷 | 3 | 2,496 | 2,240 |
| 報告 | 3 | 2,268 | 2,012 |
| 期中／期末 | 4 | 3,027 | 2,771 |

怪物遠距隱藏，省電模式減少飄頁與花帶細節；技能使用有限幾何與短生命期，
不增加逐技能動態光源。OS reduced-motion 偏好會停止擺動與旋轉，保留命中與預警。
場景卸載釋放獨佔幾何、材質、線段與角色骨架資源。

## 驗證結果
- npm run typecheck：通過。
- npm test：206 通過，0 失敗。
- npm run build:site：通過。
- git diff --check：通過。
- 使用同一角色／怪物工廠匯出 GLB，經 Blender CPU 離線渲染檢視形體。
  離線燈光與遊戲不同，不算遊戲畫面驗收。
- 目前雲端瀏覽器無法建立 WebGL context，因此主遊戲畫面、技能實際構圖、
  手機 FPS 與長時間溫度尚待實機驗證。
- 建置仍有大於 500 kB 的 chunk 提示，未以調高警告門檻消除。
