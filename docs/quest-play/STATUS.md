# 收集、負荷與巡邏

本線擁有 `src/game/rpg/data.ts` 的委託與巡邏、`src/game/rpg/store.ts` 的收集與擊退計數、`src/game/rpg/AdventureHud.tsx` 的學期委託，以及 `scripts/quest-play.test.mjs`、`scripts/quest-play-capture.mjs`。

儲存庫裡沒有 AGENTS.md。沒有另寫一份。

這一層用記憶、負荷和提神來排委託，用注意力被拆開的地點來補巡邏。虛構同學許回站在圖書館門外，問那一頁是怎麼掉的。後面談話會引用玩家實際選的歸因和恢復方式。玩家不是受試者。文案不把停一下或喝一杯寫成治療，也不用連續登入、假性短缺或愧疚來推人。兩條路的經驗相同。

主遊戲入口是學期裡的「學期委託」、走到新的巡邏點，以及走到許回按「與許回交談」。收集只算補給和掉落實際進袋的數量。領取委託和許回發的筆記都不會再算進收集。背包滿了、獎勵掉在地上再撿起來，仍然不算。地上那一疊會記住哪些是委託或對話留下的，存檔再讀回來也記得。補給和擊倒溢出來的仍然算。`MAIN_INTEGRATION` 沒有改。許回用的是既有的中國文學學系 id。沒有新的科系 id，也沒有學期時鐘。

十隻巡邏是小考或分組報告。東校區原本那串生成點沒有改。站點是估計位置。畫面是 SwiftShader、1280×720，以及 390×780 的觸控模擬。這不是手機，也不是 RTX 3060。

細節見 VALIDATION.md、CHECKPOINT.json。
